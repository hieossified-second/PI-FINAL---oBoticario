📦 Arquitetura de Armazenamento JSON

O sistema utiliza arquivos JSON estruturados para armazenar todas as tabelas e entidades (Usuários, Clientes, Produtos, Vendas e Financeiro). As alterações dinâmicas realizadas são persistidas em tempo real.
